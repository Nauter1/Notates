# HOW TO RUN: <br/>
Arendaja keskkonna seadistamine ja projekti käivitamine<br/><br/>

Klooni repositoorium<br/>
Ava kaust VS Code-iga või muu IDE-ga<br/>
Ava terminal (cmd) ja mine backend kausta: cd backend<br/>
installi Node-i paketid: npm install<br/>
Tee kindlaks et .env on olemas (backend kaustas) ja info on täidetud kohaliku või zone.ee mariadb jaoks.<br/>
Käivita arendus: npm run dev<br/><br/>
